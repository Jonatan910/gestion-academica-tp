# Gestión Académica CET N° 33

Sitio web institucional del Centro de Educación Técnica N° 33 de General Roca, Río Negro. Presenta información sobre la orientación Maestro Mayor de Obras y una intranet de demostración para cargar estudiantes.

## Tecnologías

- HTML5 semántico
- CSS3 con Flexbox, Grid y diseño Mobile First
- Bootstrap 5 y Bootstrap Icons
- JavaScript para validar y mostrar estudiantes
- Git y GitHub para el control de versiones

## Páginas

- `index.html`: información institucional, oferta educativa, historia y equipo directivo.
- `intranet.html`: formulario y tabla de estudiantes.
- `contacto.html`: ubicación, correo electrónico y horarios.

## Uso

Abrí `index.html` en un navegador o visitá la versión publicada en [GitHub Pages](https://jonatan910.github.io/gestion-academica-tp/).

En la intranet se pueden cargar estudiantes. La información se mantiene mientras la página está abierta y se borra al recargarla.
